# HTTP API задач в памяти

net/http, JSON, маршруты с методом и id, map и sync.Mutex. GET/POST /tasks, GET/PUT/DELETE /tasks/{id}. Сервер слушает :8080; данные существуют только до остановки процесса. PUT меняет Done и непустой Title.

Учебная папка `OOP/http`. Код сохранён в исходном состоянии.

## Структура

- `.gitignore`
- `go.mod`
- `main.go`

## Требования и команды

Проверено на Windows с Go 1.27.1 (windows/amd64); `go.mod` требует Go 1.27.1. Команды выполняются из корня репозитория. Для самостоятельной публикации добавлен go.mod; исходные .go не изменялись.

Точка входа: `main.go`.

```sh
go run .
```

После запуска доступен http://localhost:8080/tasks. Проверены GET списка и POST задачи; сервер остановлен после проверки.

```sh
go test ./...
go vet ./...
```
